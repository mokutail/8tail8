# 8tail8-tools

シナリオづくりと配布に使う道具。

- [地雷シートメーカー](https://mokutail.github.io/8tail8-tools/jirai-sheet/) — 含まれる要素にチェックすると、地雷・注意事項チェックシートの画像(PNG)ができる
- [KP進行ボード](https://mokutail.github.io/8tail8-tools/kp-board/) — シナリオ本文から情報・秘匿の一覧を作り、卓ごとに渡したかをチェック。卓の比較やメモも
- [告知文メーカー](https://mokutail.github.io/8tail8-tools/post-maker/) — シナリオの公開・更新のお知らせを、Xの140字に収めて作る
- [BOOTH説明文メーカー](https://mokutail.github.io/8tail8-tools/booth-maker/) — シナリオの情報を入れると、BOOTHの商品説明に貼れる文章ができる

入力した内容は、使っている人のブラウザの中にだけ保存されます。
